# Alcance de la evaluación parcial 3

La pauta adjunta «Integrando backend y frontend a la tienda online» y su Anexo 1 evalúan una tienda con productos, pedidos, usuarios y tres roles. Las mejoras de esta rama atienden ese alcance.

El documento «DSY1104 - Forma A - Veterinaria San Marcos.docx» que ya estaba en este repositorio describe otro alcance: citas, mascotas, fichas clínicas, vacunación, reportes, microservicios independientes y acceso autenticado a todas las vistas. La aplicación actual es una tienda y su backend es una sola aplicación Spring Boot organizada por capas.

El equipo debe confirmar con el profesor cuál documento aplica. Si también exige el caso clínico, faltan esos módulos y la separación en microservicios. Una arquitectura por capas no constituye una arquitectura de microservicios.

Esta entrega no implementa cobros reales ni emisión tributaria en el SII. El checkout registra un pedido y el medio de pago seleccionado. El resultado de compra confirma ese registro.
